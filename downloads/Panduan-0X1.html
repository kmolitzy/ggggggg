Keyboard yang nyata

IME Android, Ctrl/Alt/Shift/Win, Esc/Tab, F1–F12, panah dan shortcut Windows.

Sesi tetap terpisah

Foreground service, notifikasi aktif, tombol putuskan dan reconnect terbatas.

Lebih dari sentuhan

Trackpad/sentuh langsung, klik kanan, seret, scroll dua jari, zoom dan fullscreen.

Data dalam kendali

Profil, password opsional terenkripsi, verifikasi sertifikat, clipboard teks dan folder bersama.

Mulai dari PC Windows.

  1. Gunakan Windows dengan server RDP bawaan: Pro, Enterprise, Education, atau Windows Server. Windows Home tidak menyediakan fitur server RDP bawaan.
  2. Aktifkan Settings → System → Remote Desktop. Izinkan akun kamu dan pertahankan NLA aktif.
  3. Hubungkan HP melalui LAN atau VPN yang bisa menjangkau PC. PC harus menyala, tidak sleep, dan firewall mengizinkan RDP.
  4. Di 0X1, masukkan IP/host, port 3389, username seperti PC\andi, dan password Windows — bukan PIN Windows Hello.
  5. Cocokkan sertifikat PC sebelum menekan Percayai. Simpan profil jika diperlukan.

Akses hanya PC yang kamu miliki/diizinkan. Jangan mengekspos port RDP langsung ke internet. RDP bukan screen mirroring; Windows dapat mengunci layar lokal dan menerapkan kebijakan sesi sendiri.

Keluar aplikasi, bukan keluar sesi.

Aktifkan Tetap aktif di background, izinkan notifikasi, dan pilih penggunaan baterai Tidak dibatasi bila tersedia. Tekan Home atau pilih Lanjut di background. Buka lagi lewat notifikasi/halaman utama.

Foreground service membantu mempertahankan sesi, bukan jaminan hidup selamanya. Force stop, reboot, jaringan/VPN putus, Doze, pembatasan Android/OEM atau timeout server tetap dapat menghentikannya. Mode background memakai baterai dan data lebih banyak.

Kontrol yang perlu kamu tahu.

Keyboard & shortcut

Keyboard membuka IME Android. Fn / ↑↓ menampilkan function keys dan navigasi. Bar tombol bisa digeser horizontal. Ctrl/Alt/Shift/Win: ketuk menahan, ketuk lagi melepas; tombol aktif berwarna putih. Tools → Shortcut keyboard menyediakan kombinasi siap pakai. Ctrl+Alt+End membuka keamanan Windows pada sesi RDP.

Mouse, scroll & zoom

Trackpad: geser menggerakkan kursor. Sentuh langsung: ketuk posisi desktop. Ketuk kiri, ketuk dua kali untuk klik ganda, tahan untuk klik kanan. Dua jari untuk scroll; cubit untuk zoom 1×–4×. Mouse → Mode seret menahan klik kiri sampai jari dilepas. Fit mengembalikan tampilan.

Clipboard & folder bersama

Tools → Clipboard teks melakukan transfer manual. Setelah mengirim clipboard HP ke PC, gunakan Ctrl+V di PC. Folder bersama harus diaktifkan sebelum connect; di File Explorer buka \\tsclient\0X1. Impor/ekspor lewat pengelola folder 0X1; maksimal impor 100 MB/file. PC tujuan bisa membaca, menulis, dan menghapus isi folder yang dibagikan. Ekspor file penting sebelum uninstall.

Keamanan & batas v1

Password yang dipilih untuk disimpan memakai AES-GCM/Android Keystore. Sertifikat tidak dikenal atau berubah meminta konfirmasi; pemeriksaan tidak diabaikan otomatis. Tidak ada iklan, analytics, atau server perantara. Audio output dan H.264 bergantung server/perangkat. V1 belum menyediakan RD Gateway, SSO Entra/Azure, RemoteApp, clipboard gambar, printer, mikrofon/kamera, multi-monitor atau sesi banyak PC sekaligus.
